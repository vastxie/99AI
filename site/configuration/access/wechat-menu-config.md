# 微信公众号菜单

::: info 扩展包
本页功能由微信扩展包提供（服务端 `WECHAT_PACK_ENABLED`，用户端与管理端 `VITE_WECHAT_ENABLED`）。关闭或删除该包后，本页菜单与接口一并消失，登录方式里不再出现微信。开关说明见 [扩展包开关与裁剪](/deployment/packs)。
:::

公众号底部菜单在这里维护。用户可以通过菜单跳转网页、打开小程序、接收文字回复等。

- 后台入口：登录接入 / 微信配置 / 微信公众号菜单

## 使用前提

配置菜单前必须先完成 [微信登录配置](./wechat-login-config) 中的 AppId、Token 和 AppSecret。否则页面会提示先完成微信公众号基本配置。

官方指引：

- [微信自定义菜单创建接口](https://developers.weixin.qq.com/doc/offiaccount/Custom_Menus/Creating_Custom-Defined_Menu.html)
- [微信公众平台素材管理](https://mp.weixin.qq.com/)

## 菜单数量限制

| 类型 | 限制 |
| --- | --- |
| 一级菜单 | 最多 3 个 |
| 每个一级菜单下的子菜单 | 最多 5 个 |
| 菜单名称 | 建议不超过 4 个汉字或 8 个字母 |

如果一级菜单配置了子菜单，一级菜单本身通常只作为分组，不再单独配置跳转或回复内容。

## 菜单类型

| 菜单类型 | 后台值 | 说明 | 必填内容 |
| --- | --- | --- | --- |
| 回复文字 | `click` | 用户点击后公众号自动回复文字 | 回复内容 |
| 跳转网页 | `view` | 用户点击后打开指定网页 | 以 `https://` 开头的网页链接 |
| 跳转小程序 | `miniprogram` | 打开已关联的小程序 | 小程序 AppID、页面路径、备用网页 |
| 图文素材 | `media_id` | 发送图文素材 | 素材 ID |
| 图文链接 | `view_limited` | 跳转到图文消息链接 | 图文链接 |

## 配置流程

1. 点击“添加”，新增一级菜单。
2. 选中菜单，在右侧填写名称。
3. 如果需要二级菜单，点击“添加子菜单”。
4. 为最终点击项选择菜单类型。
5. 填写对应的回复内容、网页链接、小程序信息或素材 ID。
6. 点击“保存”。
7. 等待微信客户端刷新，通常几分钟后生效。

## 素材选择

当菜单类型选择“图文素材”时，可以点击“选择素材”。页面会从微信公众号素材库读取图文、图片、视频、语音素材。

如果列表为空，请先登录 [微信公众平台](https://mp.weixin.qq.com/) 创建素材，再回到后台重新选择。

## 常见问题

### 保存后手机微信里没马上变化？

微信客户端有缓存，通常需要几分钟。测试时可以重新关注公众号，或切换账号查看。

### 跳转网页打不开？

检查链接是否以 `https://` 开头，域名是否可访问，以及是否需要在微信公众平台配置业务域名或网页授权域名。

### 图文素材选择不到？

确认公众号素材库中已存在素材，并且 AppId、AppSecret 可以正常获取 access_token。
