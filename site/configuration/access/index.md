# 登录接入

账号密码是内核自带的登录方式；邮箱、手机号、GitHub、微信登录和 Bot 通道分别由对应的扩展包提供。

## 页面清单

| 页面 | 后台入口 | 用途 |
| --- | --- | --- |
| [登录配置](./login-config) | 登录接入 / 登录配置 | 账号密码自助注册开关，以及邮箱 / 手机号 / GitHub 登录渠道包各自的页签 |
| [微信配置](./wechat-config) · 微信包 | 登录接入 / 微信配置 | 微信开放平台网站登录、公众号登录、公众号消息与菜单 |
| [Bot 通道](./bot-channel) · 微信包 | 登录接入 / Bot 通道 | 开启微信 Bot、配置默认模型和语音消息识别 |

## 推荐配置顺序

1. 先确认 [基础信息](/configuration/platform/base-configuration) 中的网站地址。
2. 再看 [登录配置](./login-config)：账号密码注册默认开放；需要邮箱、手机号或 GitHub 登录时配置对应页签。找回密码需要至少一个验证码渠道。
3. 需要 PC 微信登录或公众号扫码登录时，配置 [微信登录配置](./wechat-login-config)。
4. 需要公众号底部菜单时，配置 [微信公众号菜单](./wechat-menu-config)。
5. 要让用户通过微信直接对话时，开启 [Bot 通道](./bot-channel)。

## 密钥安全

- 只在可信网络和设备上填写密钥；AppSecret、SecretKey、Client Secret 只保存在后台配置，不会下发到用户端。
- 密钥重置后同步更新后台，旧密钥失效会导致登录、发信和回调失败。
