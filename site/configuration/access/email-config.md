# 登录配置：邮箱登录

::: info 扩展包
本页功能由邮箱登录扩展包提供（服务端 `EMAIL_PACK_ENABLED`，管理端 `VITE_EMAIL_ENABLED`）。关闭或删除该包后，页签与邮箱验证码入口一并消失，其余登录方式不受影响。开关说明见 [扩展包开关与裁剪](/deployment/packs)。
:::

邮箱入口和验证码统一在这里配置。当前支持两种发信通道：

- **SMTP 邮箱**：通过标准 SMTP 协议发送验证码邮件。
- **腾讯云邮件**：适合已经使用腾讯云 SES 的站点，可复用系统腾讯云密钥。

- 后台入口：登录接入 / 登录配置 / 邮箱登录

## 配置项怎么填

### 基础开关

| 配置项 | 用途 | 填写建议 |
| --- | --- | --- |
| 开启邮箱注册/登录 | 控制用户端是否展示邮箱验证码入口 | 发信通道测试可用后再开启 |
| 发信通道 | 选择 SMTP 邮箱或腾讯云邮件 | 已有邮箱授权码选 SMTP；使用腾讯云 SES 选腾讯云邮件 |

### SMTP 邮箱

| 配置项 | 用途 | 从哪里找 | 填写建议 |
| --- | --- | --- | --- |
| SMTP 服务器地址 | 邮件发送服务器 | 邮箱服务商后台 → SMTP/POP3/IMAP 设置 | 例如 `smtp.example.com`，不要填写网页版邮箱地址 |
| SMTP 服务器端口 | SMTP 连接端口 | 邮箱服务商 SMTP 设置页面 | 常见为 `465` 或 `587` |
| SMTP 用户名称 | SMTP 登录账号 | 邮箱服务商 SMTP 设置页面 | 通常是完整邮箱地址，例如 `notice@example.com` |
| SMTP 用户密码 | SMTP 授权码或应用专用密码 | 邮箱服务商安全设置、客户端授权码或应用密码页面 | 优先使用授权码，不建议使用主登录密码 |
| 邮箱 SSL 配置 | 决定是否使用 SSL 连接 SMTP | 按邮箱服务商端口说明判断 | 465 通常开启；587 通常关闭本开关，由服务商升级为 STARTTLS |

### 腾讯云邮件

| 配置项 | 用途 | 从哪里找 | 填写建议 |
| --- | --- | --- | --- |
| SecretId / SecretKey | 调用腾讯云邮件 API 的密钥 | 腾讯云控制台 → 访问管理 → API 密钥管理 | 可与短信、内容审核等腾讯云能力共用，也可单独创建低权限子账号 |
| 地域 | 腾讯云接口地域 | 腾讯云邮件服务所在地域 | 不确定时可使用默认 `ap-guangzhou` |
| 发件地址 | 邮件 From 地址 | 腾讯云邮件推送 SES → 发信地址 | 必须是腾讯云已验证通过的发件地址 |
| 发件名称 | 收件箱中显示的发件人名称 | 自行填写 | 例如 `99Agent 通知` |
| 回复地址 | 用户回复邮件时使用的邮箱 | 自行填写 | 可选；不填时按腾讯云默认处理 |
| 模板 ID | 腾讯云邮件模板 | 腾讯云邮件推送 SES → 邮件模板 | 可选；填写后使用模板发送验证码 |

腾讯云邮件模板可使用以下变量：

| 变量 | 说明 |
| --- | --- |
| `code` | 邮箱验证码 |
| `siteName` | 站点名称 |
| `siteUrl` | 站点地址 |
| `expireMinutes` | 验证码有效分钟数，当前为 `10` |

如果不填写模板 ID，系统会尝试使用腾讯云接口的 Simple 内容发送验证码。部分腾讯云账号可能要求必须使用审核通过的模板，此时请填写模板 ID。

## 配置步骤

### 使用 SMTP 邮箱

1. 在你的邮箱服务商后台开启 SMTP 服务。
2. 获取 SMTP 地址、端口、账号和授权码。
3. 回到 后台填写配置。
4. 在登录配置的“邮箱登录”中选择“SMTP 邮箱”。
5. 开启邮箱注册和登录。
6. 打开用户端，使用邮箱验证码测试登录。

### 使用腾讯云邮件

1. 在腾讯云邮件推送 SES 中完成发信域名验证。
2. 创建并验证发件地址。
3. 如账号要求模板发送，创建验证码模板并等待审核通过。
4. 回到 后台，在“邮箱登录”中选择“腾讯云邮件”。
5. 填写 SecretId、SecretKey、地域、发件地址和可选模板 ID。
6. 开启邮箱注册和登录。
7. 打开用户端，使用邮箱验证码测试登录。

## 常见 SMTP 端口

| 端口 | 常见用途 | SSL 设置 |
| --- | --- | --- |
| 465 | SSL SMTP | 开启 |
| 587 | STARTTLS | 通常关闭 SSL 开关，由服务商升级连接 |
| 25 | 传统 SMTP | 很多云服务器默认限制，不建议优先使用 |

## 常见服务商位置

不同邮箱服务商入口名称不同，通常都在“设置 / 账号 / 客户端授权 / POP3/SMTP/IMAP”附近。

| 服务商 | 常见入口 | 备注 |
| --- | --- | --- |
| QQ 邮箱 | 设置 → 账户 → POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务 | 生成授权码后填入 SMTP 用户密码 |
| 163 / 126 邮箱 | 设置 → POP3/SMTP/IMAP → 客户端授权密码 | 使用授权密码，不使用网页登录密码 |
| 企业微信邮箱 | 管理后台或邮箱设置 → 客户端专用密码 / SMTP 服务 | 企业管理员可能需要先允许客户端收发 |
| 阿里邮箱 | 邮箱设置 → 客户端设置 / 安全设置 | 按页面给出的 SMTP 地址和端口填写 |

## 常见问题

### 为什么密码正确但发不出去？

很多邮箱不允许直接使用登录密码，需要在邮箱后台生成“SMTP 授权码”或“应用专用密码”。

### 云服务器上发信失败怎么办？

检查云厂商是否限制 25 端口。建议优先使用 465 或 587，并确认安全组允许出站访问。

### 开启后用户端没有邮箱入口？

先确认“开启邮箱注册/登录”已打开，再刷新用户端页面。

### 腾讯云邮件为什么提示模板相关错误？

腾讯云邮件推送的部分账号需要使用审核通过的模板发送。请在腾讯云 SES 中创建验证码模板，并在后台填写模板 ID。模板变量建议使用 `code`、`siteName`、`siteUrl` 和 `expireMinutes`。

### 腾讯云邮件的 Secret 会影响短信配置吗？

邮件、短信、内容审核和微信 Bot 语音识别共用系统腾讯云 SecretId、SecretKey 和地域。修改这些字段会影响同一套腾讯云能力，建议使用同一个腾讯云账号统一管理。
