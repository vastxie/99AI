## 微信 Bot 功能

| 配置项 | 说明 |
| --- | --- |
| 启用状态 | 开启后，用户可在账户管理中绑定微信 Bot，并通过微信发起对话；关闭后立即停止接收微信消息、不再发起新的对话（已在生成的回复会照常发完），绑定入口同时关闭，已有绑定保留；重新开启后自动恢复已绑定的用户，不需要重启服务 |
| 微信Bot使用模型 | 微信 Bot 渠道默认使用的模型，按已配置模型的 ID 保存；可选择未开启前台展示的模型，留空或模型不存在时回退系统默认模型 |

开启后建议先用测试账号完成绑定，再开放给正式用户。

## 语音消息识别

微信 Bot 的语音消息识别使用腾讯云语音识别的一句话识别能力。这里填的是腾讯云账号的 API 密钥，不是微信公众号 AppSecret。

| 配置项 | 用途 | 从哪里找 | 填写建议 |
| --- | --- | --- | --- |
| 启用状态 | 是否允许识别微信语音消息 | 后台选择 | 开启前先确认腾讯云语音识别服务已开通 |
| SecretId | 腾讯云 API 访问密钥 ID | [腾讯云控制台](https://console.cloud.tencent.com/) → 访问管理 → 访问密钥 → API 密钥管理 | 常见格式以 `AKID` 开头，建议使用子账号密钥 |
| SecretKey | 腾讯云 API 访问密钥 Key | 腾讯云控制台 → 访问管理 → 访问密钥 → API 密钥管理 | 创建后及时保存，不要放到公开截图或文档中 |
| Region | 腾讯云接口地域 | 腾讯云语音识别文档或接口调用地域 | 默认可用 `ap-guangzhou`；如腾讯云账号限制了地域，按实际地域填写 |

### 腾讯云准备工作

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)。
2. 搜索并开通“语音识别 ASR”服务。
3. 确认账号可使用“一句话识别”能力。
4. 进入“访问管理 → 访问密钥 → API 密钥管理”，创建或查看 SecretId 和 SecretKey。
5. 建议使用子账号密钥，并只授予语音识别所需权限。
6. 回到 后台填写 SecretId、SecretKey 和 Region。

同一组腾讯云 SecretId、SecretKey 和 Region 与邮箱、短信、内容审核共用；在任一页面保存后，其他页面会读取同一配置。

官方指引：

- [腾讯云一句话识别](https://cloud.tencent.com/document/api/1093/35646)
- [腾讯云 API 密钥管理](https://console.cloud.tencent.com/cam/capi)

## 通道状态

| 指标 | 说明 |
| --- | --- |
| 绑定用户 | 已绑定微信 Bot 的用户数量 |
| 活跃用户 | 当前可正常使用的绑定用户 |
| 过期用户 | 绑定已过期的用户 |
| 异常用户 | 绑定状态异常的用户 |

点击“查看用户列表”可以查看用户 ID、通道用户 ID、状态、绑定时间，并手动禁用或启用绑定关系。

## 配置流程

1. 开启微信 Bot 功能。
2. 选择微信 Bot 默认使用的模型；如果暂不指定，可留空使用系统默认模型。该模型可以不对用户端模型列表开启展示。
3. 如果需要语音消息，开启语音消息识别。
4. 在腾讯云“访问管理 → API 密钥管理”获取 SecretId 和 SecretKey。
5. 填写地域，常用值如 `ap-guangzhou`。
6. 使用测试用户绑定微信 Bot。
7. 发送文本和语音消息，确认能正常回复。

## 常见问题

### 开启微信 Bot 后用户不能绑定？

先确认微信相关能力已配置完成，再检查用户端账户管理中是否出现绑定入口。

### 语音识别失败？

检查腾讯云语音识别服务是否开通、密钥是否有效、地域是否正确、腾讯云账户是否欠费或被限流。

### 可以先不开语音识别吗？

可以。不开启语音识别时，用户仍可通过文本消息使用微信 Bot。

### 微信 Bot 使用模型会影响网页对话吗？

不会。该配置只影响用户通过微信 Bot 渠道发起的对话，网页端新对话和用户手动选择的模型仍按原有逻辑生效。即使这里选择了未开启的模型，也只是作为微信 Bot 渠道专用模型使用。
