# 配置概述

后台先把基础链路跑通：能登录、能对话、文件能上传。用户文件与临时处理环境分开管理；文件存储页可设置上传、成果和保留技能共同使用的账号额度。再按需要开放登录渠道、微信和 MCP 工具；装了商业包的站点再配套餐与支付。

## 管理后台入口

- 后台地址：`https://你的域名/admin`（由部署时的 `ADMIN_SERVE_ROOT` 决定）
- 初始管理员账号：`super`
- 初始管理员密码：首次启动时设置，见 [部署指南](/deployment/#first-start)：优先取 `.env` 的 `ADMIN_INITIAL_PASSWORD`（8 – 30 个字符）；未配置时随机生成并写入 `server/storage/initial-admin-password.txt`（可用 `ADMIN_INITIAL_PASSWORD_FILE` 改路径）。没有固定的默认密码。

首次登录后立即修改管理员密码并删除密码文件，并确认站点已经配置 HTTPS。支付、微信登录、文件访问和回调通知都依赖一个稳定可访问的站点地址。

## 推荐配置顺序

| 顺序 | 配置模块 | 先完成什么 |
| --- | --- | --- |
| 1 | [平台设置](/configuration/platform/) | 网站地址、站点名称、Logo、SEO、语言、公告协议和文件存储 |
| 2 | [AI 能力](/configuration/ai/) | 至少一个可用模型、Agent 单次调用上限与输入限制、私有文件策略 |
| 3 | [登录接入](/configuration/access/) | 账号密码自助注册开关；按需配置邮箱、手机号、GitHub、微信登录与 Bot 通道 |
| 4 | [用户运营](/configuration/users/) | 登录设备数；装了商业包再定注册赠送、签到与游客额度 |
| 5 | [支付财务](/configuration/payment/) · 商业包 | 套餐、支付参数、支付配置、订单管理 |
| 6 | [安全风控](/configuration/security/) · 内容安全包 | 内容审核、白名单、违规记录 |

## 扩展包页面

侧边栏里带「· 商业包」「· 微信包」等标记的页面由扩展包提供，关闭或删除对应的包后菜单不再出现。开关与影响见 [扩展包开关与裁剪](/deployment/packs)。

## 配置前检查

- 域名已经解析到服务器，并能通过 HTTPS 访问。
- 后台管理员密码已经修改。
- MySQL、Redis、后端服务和沙箱镜像都在正常运行。
- 支付、微信、短信、存储等第三方平台账号已经准备好。
- 涉及密钥的页面只在可信网络和可信设备中操作。

## 保存规则

大多数配置项在失焦、切换开关或点击保存后立即写入后台。同一页面的保存按顺序逐个提交：快速连续切换开关或修改字段，以最后一次为准；保存中的开关显示加载状态。保存失败时，界面回到上一次保存成功的值（如果你已经接着改成别的内容，保留你正在输入的内容）。保存后到用户端实际走一遍，不要只看管理端是否显示成功。

如果配置没有马上生效，先刷新用户端页面；涉及模型、沙箱、支付回调和微信回调的配置，还需要确认服务端日志没有报错。
