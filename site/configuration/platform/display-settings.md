# 界面外观

用户打开首页时看到的语言、水印等展示，都由界面外观控制。

- 后台入口：平台设置 / 界面外观

<!-- 截图占位：界面外观页面，包含语言设置和全局水印。 -->

## 配置项

| 配置项 | 说明 | 建议 |
| --- | --- | --- |
| 启用的语言 | 用户端可选择的语言列表 | 至少保留一种语言 |
| 默认语言 | 新用户首次进入时使用的语言 | 国内站点通常选择简体中文 |
| 显示全局水印 | 开启后在对话页面显示用户名水印 | 内部或私有化项目可开启，增强内容追溯能力 |

## 多语言配置

内置语言包目前只有简体中文和 English。先选择启用语言，再选择默认语言。默认语言必须包含在启用语言中；如果你把默认语言对应项取消勾选，系统会自动要求重新选择。

<!-- 截图占位：启用语言和默认语言配置区域。 -->

启用多语言后，用户可以在设置的「通用」页签里切换界面语言。

<!-- 截图占位：用户端设置「通用」页签里的语言切换入口。 -->

## 用户端展示效果

语言和水印都直接影响用户端第一屏，保存后打开用户端确认。

<!-- 截图占位 CFG-PLATFORM-DISPLAY-USER-EFFECT-01：用户端首页，标出语言切换入口和水印。 -->

## 常见问题

### 可以只保留中文吗？

可以。只要启用语言中至少保留一项，并将默认语言设为这项即可。
