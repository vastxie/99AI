# 平台设置

上线前先把站点基础信息、用户端外观、公告协议和文件存储配置对齐。

## 页面清单

| 页面 | 后台入口 | 用途 |
| --- | --- | --- |
| [基础信息](./base-configuration) | 平台设置 / 基础信息 | 设置网站名称、网站地址、Logo、备案信息和 SEO |
| [界面外观](./display-settings) | 平台设置 / 界面外观 | 控制用户端启用的语言、默认语言和全局水印 |
| [公告协议](./announcement-settings) | 平台设置 / 公告协议 | 设置站内公告和用户协议弹窗 |
| [文件存储](./storage-config) | 平台设置 / 文件存储 | 为公共文件和私有文件各选一种存储方式，并配置用户文件策略；对象存储选项随存储包出现 |

## 上线前建议

1. 先填写 [基础信息](./base-configuration)，尤其是网站地址：登录回调、支付回调、文件访问和跨域白名单都以它为准。
2. 再检查 [界面外观](./display-settings)，确认启用的语言和默认语言。
3. 需要首次访问弹窗时，配置 [公告协议](./announcement-settings)。
4. 用户会上传文件、图片、视频时，配置 [文件存储](./storage-config)。

## 注意事项

- 网站地址必须带协议并使用正式域名，不要填 `localhost` 或内网 IP。
- 切换存储方式不会自动搬迁历史文件，正式环境不要来回切换。

「文件存储」中的私有链接有效期统一用于用户上传和工具产物，默认 600 秒。来源查询和文件清理见 [私有文件](/configuration/ai/private-file-management)。
