# 基础信息

站点名称、站点地址、Logo 等站点信息都在基础信息里维护。上线前建议一次填完整，后续只做必要的小幅调整。

- 后台入口：平台设置 / 基础信息

## 配置项

| 配置项 | 说明 | 建议 |
| --- | --- | --- |
| 网站名称 | 用户端和浏览器中展示的网站名称 | 使用对外品牌名，例如 `99Agent` |
| 网站地址 | 生成登录、支付、微信回调、文件访问、CORS 白名单等链接和安全策略的基础地址 | 必须带协议，例如 `https://www.example.com` |
| 公司/组织名称 | 页脚版权或站点归属信息 | 填主体公司、团队或组织名称 |
| 网站备案号 | ICP 备案号 | 中国大陆站点建议填写 |
| 公安备案号 | 公安联网备案号 | 有备案后再填写 |
| 网站 Logo | 用户端展示的品牌 Logo | 推荐透明背景 PNG，使用清晰横版或方形图 |
| 网站图标 | 浏览器标签页图标 | 推荐 `.ico` 或 512 x 512 PNG |
| 网站标题 | SEO 标题和浏览器标题 | 简洁说明站点定位 |
| 网站描述 | 搜索引擎摘要 | 写清楚站点能提供什么，不堆关键词 |
| 网站关键词 | SEO 关键词 | 用英文逗号分隔，数量不宜过多 |

## 配置步骤

1. 填写网站名称和网站地址。
2. 上传或粘贴 Logo 和 Favicon 地址。
3. 填写备案信息。
4. 补充网站标题、描述和关键词。
5. 打开用户端首页，检查标题、图标、Logo 和页脚显示是否正确。

## 用户端展示位置

基础信息会出现在用户端首页、浏览器标签页、页脚版权等位置。保存后打开用户端完整检查一次。

## 网站地址怎么填

网站地址应填写用户实际访问的公开地址，例如：

```text
https://www.example.com
```

不要填写：

```text
http://localhost:9002
http://127.0.0.1:9002
http://服务器内网IP
```

微信登录、支付回调、服务端 CORS 白名单等都依赖这个配置。这里写错，很容易出现“后台都填了，但第三方平台回调不到”或“浏览器 / WebSocket 被跨域拦截”的情况。

生产环境不会默认放行任意跨域来源。开发环境会额外允许本机 `localhost`、`127.0.0.1` 和 `[::1]` 调试地址。

## 图片建议

| 图片 | 推荐尺寸 | 说明 |
| --- | --- | --- |
| Logo | 512 x 512 或横版高清图 | 保持清晰，不要用带大面积留白的截图 |
| Favicon | 512 x 512 | 浏览器会自动缩放，图形要简单 |

## 常见问题

### 修改 Logo 后前台没变化？

先刷新用户端页面。如果仍然没有变化，检查图片地址能否直接在浏览器打开，并确认图片地址是 HTTPS。

### 备案号必须填吗？

如果站点部署在中国大陆并对外访问，通常需要按监管要求完成 ICP 备案和公安备案。海外站点可按实际情况留空。

### SEO 信息会马上生效吗？

不会。后台保存后只是更新站点展示内容，搜索引擎重新抓取需要时间。
