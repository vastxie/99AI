# 公告协议

站内公告和用户协议都在这里维护。公告适合发布版本通知、维护提示和运营说明；用户协议用于放置服务条款、隐私说明或使用规范。

- 后台入口：平台设置 / 公告协议

<!-- 截图占位：公告协议页面，包含公告和用户协议两个标签页。 -->

## 公告协议项

| 配置项 | 说明 | 建议 |
| --- | --- | --- |
| 公告标题 | 公告弹窗或公告区域的标题 | 例如“系统公告”“维护通知” |
| 自动弹出 | 用户进入站点时是否自动弹出公告 | 重要通知开启，普通说明不建议频繁弹出 |
| 公告内容 | 公告正文，支持 Markdown | 控制篇幅，重要信息放在前面 |

## 用户协议配置项

| 配置项 | 说明 | 建议 |
| --- | --- | --- |
| 协议标题 | 协议弹窗标题 | 例如“用户协议与隐私说明” |
| 展示用户协议 | 开启后，登录 / 注册处显示「继续即视为同意」与协议链接，用户可点开阅读协议全文；不需要勾选 | 面向正式运营建议开启 |
| 协议内容 | 协议正文，支持 Markdown | 涉及法律内容建议由专业人员确认 |

## 内容编辑建议

公告和协议支持 Markdown。下面是一段可参考的基础结构：

```markdown
## 服务说明

欢迎使用本站。使用前请确认你已了解平台的使用范围和内容规范。

- 不要上传违法、侵权或涉及隐私的内容。
- 生成内容需要人工核验，重要结论请以实际情况为准。
```

## 用户端展示效果

公告是否自动弹出、协议链接是否出现在登录 / 注册处，最终要以用户端为准。发布前建议用普通用户账号打开首页与登录框，确认标题、正文排版、链接等都正常。

## 发布前检查

- 标题是否清楚。
- 链接是否能正常打开。
- 图片是否能正常显示。
- 自动弹出是否确有必要。
- 协议内容是否符合你的实际服务范围。

## 常见问题

### 公告适合放什么？

适合放版本更新、维护窗口、活动说明等短期信息。

### 用户协议可以直接复制网上模板吗？

不建议。模板只能作为参考，正式运营时应根据你的主体、服务范围、收费方式等实际情况调整。
