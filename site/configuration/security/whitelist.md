# 白名单

::: info 扩展包
本页功能由内容安全扩展包提供（服务端 `CONTENT_SAFETY_PACK_ENABLED`，管理端 `VITE_CONTENT_SAFETY_ENABLED`）。关闭或删除该包后，本页菜单与接口一并消失，对话不再做内容审核。开关说明见 [扩展包开关与裁剪](/deployment/packs)。
:::

如果品牌名、产品名或行业术语被本地敏感词库误拦，可以把这些词加入白名单放行。

## 后台入口

- **菜单路径**：安全风控 → 白名单
- **后台地址**：`/security/whitelist`

## 生效范围

白名单只对本地敏感词库生效，不影响腾讯云文本审核结果。

如果你启用了腾讯云文本审核，某个词仍被腾讯云判定违规，需要到腾讯云内容安全侧查看是否支持对应业务策略配置。

## 能做什么

列表页支持按词语搜索。白名单词语可以逐个添加并填写备注，也可以批量添加（空格或换行分隔）；已有记录可以修改词语和备注，不再需要放行的词语可以删除。

<!-- 截图占位 CFG-SECURITY-WHITELIST-02：添加白名单弹窗 -->

## 字段

| 字段 | 说明 |
| --- | --- |
| 白名单词语 | 需要放行的词语 |
| 备注 | 可选说明，建议写明放行原因 |
| 创建时间 | 白名单创建时间 |

## 批量添加

批量添加适合一次导入多个业务词。

填写规则：

- 多个词语可用空格分隔。
- 多个词语也可每行一个。
- 单次最多添加 `10000` 个词语。
- 已存在的词语会被跳过，页面会提示总数、成功数和跳过数。

<!-- 截图占位 CFG-SECURITY-WHITELIST-03：批量添加白名单弹窗 -->

## 使用建议

- 只把明确误伤的词加入白名单，不要为了省事放行过宽泛的词。
- 备注里写清楚来源，例如“品牌名”“课程名称”“客户公司名”，后续复查会更省事。
- 定期清理不再使用的词，避免白名单过长影响判断质量。
- 先看 [违规记录](./violation-records) 中的实际命中词，再决定是否加入白名单。

## 常见问题

### 添加后多久生效？

保存后即可生效，不需要重启服务。

### 白名单支持模糊匹配吗？

建议按完整词语添加。遇到多种写法时，把常见写法分别加入白名单。

### 为什么加了白名单还是被拦截？

常见原因有两个：一是当前拦截来源是腾讯云检测；二是内容里还有其他敏感词。请到 [违规记录](./violation-records) 查看违规检测来源和命中关键词。
