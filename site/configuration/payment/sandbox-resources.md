# 沙箱资源

沙箱资源页按套餐方案给用户的沙箱电脑分配资源档位：付费方案可以拿到更多内存、CPU 和磁盘，免费用户与访客用默认档。每个登录用户有一台自己的沙箱电脑，他的多个对话共用它；磁盘是这台电脑的持久存储，文件和装过的软件会一直保留。档位只影响资源，不扣积分；沙箱命令的用量按天记录，在用户详情里查看。

- 后台入口：支付财务 / 沙箱资源

## 档位怎么生效

表格第一行是默认档，给没有有效套餐的用户和访客使用；其余每行对应一个套餐方案（按 [套餐设置](./package-settings) 里的方案标识），已下架的方案也会列出，因为买过它的用户仍按它取档位。用户的会员有效时使用所购方案的档位，方案没有单独设置时回到默认档。

留空的格子沿用服务端环境变量 `SANDBOX_*` 的默认值，整张表都留空就是不按套餐区分。保存时服务端会检查每一档能否在当前服务器上创建，不合格会提示原因并拒绝保存。已保存的档位配置如果被改坏（例如直接改了数据库），服务端会拒绝所有沙箱操作而不是放宽到环境变量的额度，用户详情里的档位显示「暂不可用」；在本页重新保存即可恢复。

| 列 | 取值 | 说明 |
| --- | --- | --- |
| 内存（MB） | 128–65536 | 不超过服务器的 `SANDBOX_TOTAL_MEMORY_MB`；同一用户的多个对话共用 |
| CPU（核） | 0.25–64 | 最多两位小数 |
| 磁盘（MB） | 256–1048576 | 登录用户沙箱电脑的持久磁盘容量，写满即停；留空沿用 `SANDBOX_USER_DISK_MB`（默认 4096） |
| 临时工作区（MB） | 16–102400 | 只用于访客和未启用持久磁盘的站点；它是内存盘，必须小于同一档的内存 |
| 单次超时（秒） | 5–3600 | 单条命令的最长执行时间 |
| 每账号并发 | 1–20 | 只对访客生效（登录用户固定一台）；只能在 `SANDBOX_MAX_ACCOUNT_ACTIVE` 以内收紧 |

磁盘不占内存，所以可以比内存大得多，例如 2048 MB 内存配 8192 MB 磁盘。临时工作区是容器里的内存盘，写入的文件占用内存上限，所以它必须小于内存。

内存、CPU 和临时工作区在沙箱开机时确定。修改档位，或者用户购买、到期之后，已经在运行的沙箱沿用原来的资源，闲置回收、下次开机时按新档位分配，正在进行的任务和磁盘里的文件不会被打断。磁盘调大后在下次开机时扩容；调小不会缩小已经分配的磁盘，也不会删除文件，只是超出新容量后拒绝写文件和导入附件，用户删掉不需要的文件后即可继续。用户购买或到期后约 30 秒内开始按新档位开机。单次超时对运行中的沙箱立即生效；每账号并发在新建沙箱时检查，不会停掉已在运行的沙箱。

## 用量记录

每条沙箱命令结束后，服务端按天累计该用户的命令次数和执行耗时，保留 90 天；访客不记录。用户详情的「权益与消费」页签显示用户沙箱开机时使用的档位（运行中的沙箱沿用开机时的资源），以及近 7 天、近 30 天的命令次数与耗时。用量只用于观察，不产生扣费。

## 常见问题

**用户说磁盘满了怎么办？** 让用户在对话里删掉不需要的文件（命令在磁盘满时仍能运行），或把他的套餐换到磁盘更大的档位，下次开机时扩容。

**调低档位会删除用户的文件吗？** 不会。已经分配的磁盘不缩小，文件都保留，只是超出新容量后不能再写入新文件。

**删除对话会删除电脑里的文件吗？** 不会。对话在电脑里的工作目录会保留，同一用户的其他对话仍能看到。删除用户磁盘只能由服务器管理员在宿主机上执行，见 [安装部署](/deployment/#sandbox)。
