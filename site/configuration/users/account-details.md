# 账户明细

::: info 扩展包
本页功能由商业扩展包提供（服务端 `COMMERCE_PACK_ENABLED`，管理端 `VITE_COMMERCE_ENABLED`）。关闭或删除该包后，本页菜单与接口一并消失。开关说明见 [扩展包开关与裁剪](/deployment/packs)。
:::

用户积分每次增减都会写入账户明细，包括注册赠送、购买套餐、模型消费等。排查“积分为什么变了”时，先看这里。

## 后台入口

- **菜单路径**：用户运营 → 用户管理 → 打开某个用户的详情 → 「权益与消费」页签
- **后台地址**：`/user/detail/:id?tab=commerce`（旧地址 `/user/account-log?userId=` 会自动跳转）

账户明细按用户查看，不再有全站流水页；要查某条流水，先在用户管理里找到对应用户。

## 筛选条件

| 条件 | 说明 |
| --- | --- |
| 变更类型 | 按账户流水类型筛选 |

## 变更类型

| 类型范围 | 类型 | 说明 |
| --- | --- | --- |
| 充值类 | 注册赠送、受邀请赠送、邀请人赠送、购买套餐赠送、管理员调整、扫码支付、退款、签到奖励、管理员批量充值 | 通常显示为绿色标签 |
| 消费类 | 普通对话、图片生成、视频生成、音乐生成、其他消费 | 通常显示为红色标签 |

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 时间 | 账户变化发生时间 |
| 变更类型 | 本次积分变化的来源 |
| 变更积分 | 本次增加或减少的积分，带正负号 |
| 变更说明 | 系统记录的补充说明 |
| 记录 ID | 关联订单、业务记录或流水标识 |

## 常见排查方式

### 支付后没有到账

1. 到 [订单管理](../payment/order-list) 查询订单是否已支付。
2. 如果订单已支付，打开该用户的详情，查看「权益与消费」页签里的账户明细。
3. 查看是否存在“购买套餐赠送”记录。
4. 如果没有记录，继续检查支付回调和订单发货日志。

### 用户积分突然变少

1. 打开该用户详情的「权益与消费」页签查看账户明细。
2. 查看是否有消费类记录，例如普通对话、图片生成、视频生成等。
3. 结合 [对话记录](./chat-records) 查看对应时间段的实际使用内容。

### 管理员调整后数值不对

管理员在 [用户管理](./user-info) 中调整积分时，系统会按“目标积分 - 当前积分”生成实际变更值。请检查目标积分是否填写正确。

## 注意事项

- 账户明细是售后和财务排查的重要依据，不建议手动删除。
- 管理员调整积分前建议先截图或记录原因，便于后续追溯。
- 消费类记录不一定来自用户主动点击按钮，Agent 自动调用工具时也可能产生对应扣费。
