# 用户管理

处理账号问题时，先从用户管理定位用户。这里可以查看资料、修改账号状态、重置密码等，也可以进入用户详情查看汇总。

<!-- 截图占位 CFG-DATA-USER-INFO-01：用户管理列表页 -->

## 后台入口

- **菜单路径**：用户运营 → 用户管理
- **后台地址**：`/user/dashboard`

## 筛选条件

| 条件 | 说明 |
| --- | --- |
| 用户名称 | 按用户名模糊搜索 |
| 用户邮箱 | 按邮箱模糊搜索 |
| 手机号码 | 按手机号模糊搜索 |
| 用户昵称 | 按昵称模糊搜索 |
| 用户状态 | 按待激活、正常、已封禁、黑名单、游客筛选 |

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户头像 | 用户当前头像 |
| 用户信息 | 用户名和昵称 |
| 用户 UID | 系统生成的用户唯一标识 |
| 用户邮箱 | 绑定邮箱 |
| 用户手机号 | 绑定手机号；未绑定时显示“未绑定手机号” |
| 用户状态 | 当前账号状态 |
| 积分余额 / 会员积分 / 会员到期时间 / 已用积分 / 已用 Token | 商业包提供的五列，未装载时不显示 |
| 注册时间 | 用户注册时间 |
| 操作 | 查看详情、修改状态、重置密码；装了商业包再加调整积分、赠送套餐 |

## 用户详情

用户列表中的“详情”会进入独立用户详情页，供超级管理员快速核对账号状态、权益消费、使用概况等信息。

- **后台地址**：`/user/detail/:id`
- **访问权限**：仅超级管理员可访问；普通管理员和用户本人默认无权查看。
- **适用场景**：客服排查账号问题、核对会员和额度、判断近期使用是否异常，以及从用户视角跳转到各类完整明细列表。

<!-- 截图占位 CFG-DATA-USER-INFO-DETAIL-01：用户详情页，标出顶部用户档案、使用概览、权益与消费、登录身份与通道、安全与风险和最近事件区域。 -->

### 展示内容

| 区域 | 展示内容 |
| --- | --- |
| 顶部用户档案 | 用户名、昵称、头像、角色、状态、用户 ID、UID、脱敏邮箱、脱敏手机号、脱敏最近 IP |
| 使用概览与趋势 | 当前时间范围内的对话数、请求数、Token、活跃天数、最近使用时间，以及按模型聚合的趋势图、常用模型和主要渠道 |
| 登录身份与通道 | 邮箱、手机号、GitHub、微信等登录身份摘要，以及微信 Bot 等通道绑定摘要 |
| 权益与消费（商业包） | 可用额度、会员状态与到期时间、累计实付、当前套餐、新建沙箱档位与近期用量；未装载商业包时不显示 |
| 安全与风险 | 账号状态、累计违规次数与异常信号；装了内容安全包时还有最近违规摘要 |
| 最近动态 | 最近的模型请求、文件产物，以及扩展包提供的订单、账户变动与违规摘要 |

档案头下方是指标磁贴，其余内容按页签组织：概览、扩展包页签（如权益与消费、内容安全）、登录身份与通道、安全与风险。页面里的跳转按钮会带上当前用户筛选条件，方便继续查看完整对话记录或违规记录；账户明细直接在「权益与消费」页签内分页查看。

### 隐私边界

用户详情页默认只展示必要摘要和脱敏信息：

- 邮箱、手机号、第三方账号标识、UnionID、Bot 通道用户标识和最近 IP 会脱敏显示。
- 不展示密码、登录凭证、第三方 access token、Bot token、完整第三方 profile、完整通道配置。
- 不展示完整 prompt、完整对话正文、违规内容原文、命中词原文、Artifact Blob、下载地址、对象存储路径或私有文件真实标识。
- 最近事件中的对话、违规和 Artifact 只保留可解释摘要；需要查看完整上下文时，应到对应列表页按权限处理。

## 用户状态

| 状态 | 含义 | 适用场景 |
| --- | --- | --- |
| 待激活 | 注册后尚未完成激活或验证 | 邮箱、手机或人工审核场景 |
| 正常 | 可正常使用平台 | 默认状态 |
| 已封禁 | 禁止继续使用 | 明确违规、恶意使用 |
| 黑名单 | 更严格的限制状态 | 多次违规或风险较高用户 |
| 游客 | 未正式注册的体验用户 | 访客功能开启后产生 |

## 操作说明

### 修改状态

这里可以手动调整账号状态。封禁、黑名单等操作会影响用户继续使用平台，建议结合 [违规记录](../security/violation-records) 和实际证据处理。

<!-- 截图占位 CFG-DATA-USER-INFO-03：修改用户状态弹窗 -->

### 重置密码

为用户生成一个 16 位随机临时密码，只在操作结果里显示一次；同时撤销该用户的全部登录会话（已登录的设备需要重新登录）。

执行前请确认用户身份，通过安全的渠道把临时密码转交给用户，并提醒用户登录后尽快改成自己的密码。

### 调整积分（商业包）

弹窗会显示当前积分，管理员填写的是“调整后的目标积分”，系统会自动计算实际增减值。

例如用户当前积分为 `500`，目标积分填 `800`，系统实际增加 `300` 积分。

### 赠送套餐（商业包）

选择一个已启用的套餐规格直接发放给用户，权益按该规格的到账规则发放。

## 常见问题

### 为什么普通管理员看不到用户详情？

用户详情页汇总了身份通道、消费、风险等摘要信息，涉及用户隐私和运营判断，因此只开放给超级管理员。权限以服务端校验为准，前端菜单隐藏不是安全边界。

### 用户无法登录，先看哪里？

先进入用户详情检查用户状态、登录身份与通道摘要，再查看是否绑定邮箱、手机号或第三方登录方式。如果账号被封禁或在黑名单中，需要先确认处理原因。

### 用户忘记密码怎么办？

可以使用“重置密码”生成随机临时密码（只显示一次），安全转交给用户后让用户立即改成自己的密码；开启了邮箱或手机号验证码渠道时，用户也可以在登录框自助找回。

### 游客用户能不能修改状态？

用户管理页会显示游客状态。需要限制游客使用时，优先查看 [用户策略](./user-settings) 中的游客每日积分额度。
