# 对话记录

用户提问、模型回复、Agent 工具调用链路等都在对话记录里。排查模型异常、内容安全问题或用户反馈时，通常先从这里定位。

<!-- 截图占位 CFG-DATA-CHAT-RECORDS-01：对话记录列表页 -->

## 后台入口

- **菜单路径**：用户运营 → 对话记录
- **后台地址**：`/user/list`

## 筛选条件

| 条件 | 说明 |
| --- | --- |
| 用户名称 | 远程搜索用户名后筛选指定用户 |
| 用户询问的问题 | 按用户提问内容模糊搜索 |
| 模型 | 按实际使用的模型筛选 |

<!-- 截图占位 CFG-DATA-CHAT-RECORDS-02：对话记录筛选区 -->

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户信息 | 显示用户名和昵称 |
| 模型 | 本条记录使用的模型标识 |
| 类型 | 普通类型或 Agent 标记 |
| 用户询问/AI回复 | 对话内容摘要，点击可查看富文本预览 |
| Token 使用 | 本条记录消耗的 Token 数 |
| 时间 | 对话发生时间 |
| 详情 | 打开完整详情弹窗 |

## 详情弹窗

详情弹窗会根据记录内容展示不同区块。

| 区块 | 内容 |
| --- | --- |
| 内容 | 当前消息正文，支持 Markdown 渲染 |
| 推理内容 | 模型返回的推理摘要或思考内容，无推理内容时不显示 |
| Agent 轮次 | 按轮次展示思考、回复、多模态片段、插话和工具调用链路 |
| 工具调用链 | 展示每个工具的名称、状态、耗时、输入参数和输出结果 |
| 媒体与文件 | 图片、视频、音频、文件等关联资源信息 |
| 原始结构化信息 | 后台保留的结构化记录，供技术排查使用 |

<!-- 截图占位 CFG-DATA-CHAT-RECORDS-03：对话详情弹窗 -->

## Agent 轮次记录怎么看

Agent 会把一次任务拆成若干步骤。详情中的“Agent 轮次”会尽量结构化展示这些信息：

| 内容 | 说明 |
| --- | --- |
| 状态 | 当前 Agent 执行状态，例如 completed |
| 工具调用次数 | 本次回复实际调用了多少个工具 |
| 推理过程 | Agent 的阶段性思考摘要 |
| Agent 回复 | 最终返回给用户的正文 |
| 工具调用链 | 每个工具的名称、状态、耗时、输入参数和输出结果 |
| 原始数据 | 后台保留的结构化记录，供技术排查使用 |

## 排查场景

### 用户说“AI 没有按要求调用工具”

打开详情中的“Agent 轮次”，查看工具调用链是否存在对应工具。如果没有调用，通常需要结合用户输入、模型能力、沙箱状态和全局配置排查。

### 用户说“生成了文件但找不到”

查看“Agent 轮次”或“媒体与文件”中的文件记录。新生成的工具文件通常会以安全文件项展示，管理员可以通过文件 ID、文件名、来源能力和状态确认文件是否仍可下载或预览；旧历史记录中如果仍出现 URL 字段，应按历史数据处理，不作为新工具输出口径。

### 用户说“回答内容不完整”

查看内容、推理内容和 Agent 回复是否完整。如果后台记录完整但用户端显示不完整，可能是前端展示或网络中断问题；如果后台记录本身不完整，再继续排查模型返回和工具执行过程。

## 隐私提醒

对话记录可能包含用户上传文件内容、联系方式、业务资料等敏感信息。建议只授权给需要处理客服、审计和问题排查的管理员。
