# AI 能力

先把模型准备好，再让用户用自然语言交代任务。用户不需要挑工具，Agent 会在用户专属的沙箱里读写文件、运行命令，并按任务目标决定是否调用已接入的 MCP 工具。

## 页面清单

| 页面 | 后台入口 | 用途 |
| --- | --- | --- |
| [模型管理](./model-settings) | AI 能力 / 模型管理 | 添加对话模型、配置调用协议与 API Key、读取服务商模型列表、多模态与推理强度、上下文长度、原生搜索 |
| [MCP 服务](./mcp) | AI 能力 / MCP 服务 | 增删改、启停 MCP 服务器，测试连接并查看它提供的工具（仅超级管理员） |
| [全局配置](./advanced-config) | AI 能力 / 全局配置 | 配置 Agent 工具调用轮次上限（默认 25，范围 1–50）、模型首次响应等待上限（默认 120 秒，范围 10–600）、输入长度和全局头部预设 |
| [私有文件](./private-file-management) | AI 能力 / 私有文件 | 查看用户上传、聊天附件、沙箱产物和 AI 生成结果的记录，预览、下载或清理 |

## 推荐配置顺序

1. 在 [模型管理](./model-settings) 中添加至少一个可用模型，并用「测试模型」验证。
2. 在 [全局配置](./advanced-config) 中确认单次调用上限和输入限制。
3. 需要联网搜索等外部能力时，在 [MCP 服务](./mcp) 接入提供这些工具的 MCP 服务器。
4. 用户经常生成文件时，到 [私有文件](./private-file-management) 查看占用；保留与清理策略在 [文件存储](/configuration/platform/storage-config) 配置。

## 计费说明

模型表单里的计费系数、Token 计费、计费比例只有装载商业包时才产生扣费；没有商业包的站点这三项不影响调用。

私有文件页可按来源标识定位文件。工具产物会保留稳定文件身份，失败后同一回合重试可继续交付；访问始终按文件归属校验。
