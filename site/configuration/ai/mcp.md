# MCP 服务

MCP 服务页管理 Agent 可以调用的外部工具服务器：新增、编辑、启停和删除，并用「测试」确认服务器能连上、看到它提供哪些工具。MCP 的接入方式、身份透传和环境变量写法见 [外部接入](/deployment/integrations#mcp-服务器)。

- 后台入口：AI 能力 / MCP 服务（仅超级管理员）

## 服务器来源

列表合并两处来源。「环境变量」来自部署时的 `MCP_SERVERS_JSON`，页面上只读，改动要改环境变量并重启后端。「后台配置」是在本页保存的服务器，保存后立即生效，不需要重启（用命令行垂直包导入写入的服务器，本页打开即可看到并在其上编辑；要让运行中的服务使用它们，在本页保存一次或重启后端）。

保存按整张列表提交，并带上页面最近一次成功读取或保存时的版本：期间别人在另一个页面、或命令行导入改过配置时，保存会被拒绝并提示「配置已被其他人修改，请刷新后重试」，页面随即重新加载，避免覆盖别人的修改。列表正在刷新或加载失败时页面不允许新增、编辑、启停或删除，刷新完成（或点「重新加载」成功）后再操作。后台配置里有无法解析的条目时，页面顶部会列出原因，保存前会请你确认丢弃它们；确认期间列表被刷新过，这次保存会放弃，请重新操作。

两处出现同名服务器时，后台配置覆盖环境变量里的那一项（垂直包导入写入的服务器也属于后台配置），列表把它标为「覆盖环境变量」。在本页新增服务器时不能使用环境变量里已有的名字；已经存在的覆盖可以继续编辑，「删除覆盖」后恢复环境变量里的配置，并按环境变量的设置启用或停用。只想停用这台服务器时，关闭「启用」开关即可。

## 新增与编辑

| 字段 | 说明 |
| --- | --- |
| 名称 | 小写字母、数字、`_` 与 `-`，最长 32 位；决定模型可见的工具名 `mcp__<名称>__<工具名>` |
| 传输方式 | HTTP：地址与请求头；stdio：命令、参数、环境变量与工作目录 |
| 超时 / 工具列表缓存 | 单次调用超时；工具列表的缓存时长 |
| 透传身份 / 身份签名密钥 | 默认透传；填写密钥后身份带 HMAC 签名 |
| 允许 / 禁止的工具 | 每行一个远端工具名，支持末尾 `*`，禁止优先 |

改名等于换一台服务器，模型里原来的工具名随之失效。stdio 传输要部署人员先用 `MCP_STDIO_ENABLED` 与 `MCP_STDIO_COMMAND_ALLOWLIST` 放行命令。请求头、stdio 环境变量和身份签名密钥属于密钥，页面只显示脱敏值；不修改就保持原值，要更换时整段重新填写。服务器地址不能指向云服务器的元数据地址（如 `169.254.169.254`），保存时会被拒绝。

## 测试连接

「测试」按当前生效的配置连接服务器并重新读取工具列表，结果列出每个远端工具、模型可见名和是否被过滤。连接失败只提示检查地址、鉴权与网络，不显示远端返回的原始错误。stdio 服务器的命令没有放行时，列表的地址 / 命令列会标出「未放行」，也无法测试。
