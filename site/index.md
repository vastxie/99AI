# 99Agent

99Agent 是可私有化部署的多用户 AI Agent 基座。用户用自然语言交代任务，模型在该用户专属的沙箱里读写文件、运行命令并交付结果；管理员在后台接入模型、管理用户，并按需要装上支付、内容安全、微信等扩展包。

## 组成

- **内核**：多用户 Agent 对话所需的最小能力。账号密码登录、模型网关（自带 OpenAI Chat Completions 兼容接口）、登录用户每人一台（持久磁盘）、访客每个对话一台的 Docker + gVisor 沙箱与 `read / write / edit / bash / ls` 五个原语工具、MCP 客户端、文件资产（自带本地目录存储）、站点配置与管理后台。
- **扩展包**：其余能力都是可以整目录删除的包。`system` 级的包是内核已抽象能力的一种实现（模型协议、对象存储、登录渠道、富媒体渲染）；`feature` 级的包是独立功能域（商业计费、内容安全、微信）。删掉任何一个包，内核照常通过类型检查、测试与构建。

三端代码分别在 `server/`（NestJS 后端）、`web/`（用户端）和 `admin/`（管理后台），沙箱镜像在 `sandbox/`。
