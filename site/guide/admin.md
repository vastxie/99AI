# 管理端功能

管理员在管理端接入模型、维护站点信息、管理用户，并排查对话与执行过程。装上扩展包后会多出对应的菜单与页面。逐项配置说明见 [后台配置](/configuration/)。

## 首页

首页只做导航：按「平台设置 / AI 能力 / 用户运营 / 登录接入」分组列出各页面入口，已装载的扩展包（支付财务、安全风控等）会多出对应分组，关闭后自动消失。新站点从这里完成上线前检查，运营中的站点从这里进入日常管理。

## 平台设置

基础信息维护网站名称、网站地址、备案、Logo 与 SEO；网站地址是登录回调、支付回调、文件访问和跨域白名单的基础，必须填正式域名。界面外观决定用户端启用的语言、默认语言和全局水印。公告协议维护站内公告与用户协议。文件存储为公共文件和私有文件各选一种存储方式（本地目录内核自带，S3 / OSS / COS 随存储包出现），并集中管理用户文件的大小、保留时间与清理策略。

## AI 能力

模型管理决定用户能用哪些模型：调用协议、接口地址、API Key、绑定模型、多模态与推理强度、上下文长度，以及用户端展示的名称、图标和排序；表单里可以直接测试文本、图片、文档、视频和音频能力。全局配置决定 Agent 怎么完成任务：一次请求最多调用多少次工具、输入长度上限和全局头部预设。私有文件查看用户上传、聊天附件、沙箱产物和 AI 生成结果的记录，可预览、下载或清理。

## 用户运营

用户管理查用户、改状态、重置密码，进入用户详情查看使用趋势、常用模型、登录身份与通道、安全与风险和最近动态。对话记录按用户、提问内容和模型查记录，详情里能看到推理内容、每一轮的工具调用链（名称、状态、耗时、输入输出）和关联文件。用户策略在内核里只有最大登录设备数。

装了商业包后，用户列表多出积分余额、会员积分、会员到期时间、已用积分、已用 Token 五列和「调整积分」「赠送套餐」操作，用户策略多出「额度与赠送」卡片（注册赠送、签到奖励、访客额度），用户详情多出「权益与消费」页签（套餐、额度与该用户的账户明细）。装了内容安全包后，用户详情多出违规摘要。

## 登录接入

登录配置的「账号密码」页签决定是否开放自助注册；邮箱、手机号、GitHub 三个页签分别由对应的登录渠道包提供，配置发信 / 发短信通道与 OAuth 凭证。微信包提供「微信配置」（公众号登录、微信开放平台网站登录、自动回复、公众号菜单）和「Bot 通道」（微信 Bot、语音消息识别、绑定用户）。

## 支付财务（商业包）

套餐设置按方案和规格配置用户可购买的会员与积分包；支付配置决定用户端展示哪些支付方式与顺序；支付参数接入微信、支付宝、易支付、PayPal、Stripe 的商户参数，并提供完整支付测试；订单管理跟踪订单状态、渠道与金额；每个用户的充值、消费、签到、管理员调整等积分流水在用户详情「权益与消费」页签里查看。

## 安全风控（内容安全包）

内容审核启用敏感词过滤和腾讯云文本审核；白名单放行容易误伤的业务词；违规记录查看被拦截内容、来源和累计次数，并可直接变更用户状态。

## 上线检查清单

1. 基础信息：网站名称、网站地址（正式域名）、备案、Logo 与 SEO。
2. 至少一个稳定可用的对话模型，并用「测试模型」验证。
3. 全局配置：单次调用上限、输入长度上限、全局头部预设。
4. 文件存储：确认上传、预览、下载正常；正式站点建议对象存储。
5. 登录接入：至少一种登录方式实测走通；找回密码需要邮箱或手机号验证码渠道。
6. 用户策略：登录设备数；装了商业包再定注册赠送、签到与游客额度。
7. 商业运营站点：套餐、支付参数、支付配置，并跑一次完整支付测试。
8. 内容安全：开启审核，放行业务词，定期查看违规记录。
9. 用对话记录验证一次复杂 Agent 任务可追踪。
