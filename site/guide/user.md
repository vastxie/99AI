# 用户端功能

这一页说明部署后用户会怎样使用平台：登录、提出目标、补充资料、查看过程、拿到结果。用户不需要理解工具的区别，把目标说清楚即可。

## 登录与账号

登录框始终提供账号密码登录，后台开放自助注册时可以直接用用户名和密码注册。邮箱验证码、手机号验证码、GitHub、微信登录按站点装载的扩展包和后台开关自动出现，首次用验证码或第三方登录会自动建号。设置里的「账号」页签按登录方式列出绑定 / 解绑，并可以修改密码；找回密码需要站点开启邮箱或手机号验证码。解绑之后必须还能登录：要么还有当前可用的其他登录方式，要么已经设置了密码、且用户名或保留下来的邮箱、手机号只对应这一个账号，否则会提示先设置密码或绑定其他登录方式。解绑邮箱或手机号时，账号资料里登记的仍是这个邮箱 / 手机号才会一并清除。

## 首页与会话

首页是问候语和输入框。模型选择用于在效果、速度和成本之间切换，可选模型与推理强度由后台「模型管理」决定；侧边栏列出最近会话，可以搜索、改名、删除。

每个会话就是一条持续的 Agent 对话：发送第一条消息后会自动生成标题，之后可以继续追问、补充资料或换一个方向。

## 输入与附件

输入框支持文本，也可以上传文档（PDF、Word、Excel 等）、图片和视频，发送前有附件预览。附件会和消息一起放进你的沙箱电脑，模型可以直接读取、处理并生成新的文件。登录后每人有一台自己的沙箱电脑，多个对话共用：之前生成的文件、装过的软件都会保留，下次在任何对话里都能接着用；删除对话不会删除它在电脑里的文件。

## Agent 对话

用自然语言交代完整目标即可，例如：

- 整理这份 Excel，找出异常数据，并生成一份 Markdown 报告。
- 把这几份文档合并成一份对比表，并给出结论。
- 分析这张产品截图，指出信息层级和交互问题。

系统会根据任务内容、沙箱里可用的软件、站点预置的技能、已接入的外部工具（MCP）和模型能力，决定是否运行命令、处理文件或生成新文件。是否能联网、能调用哪些外部服务，取决于站点的配置。

## 执行过程

复杂任务不会一次回复完成。回复过程中，正文下方会显示当前状态（正在思考、正在运行命令等）；回复完成后，这一行变成「N 次工具调用 · 耗时」摘要并常驻在正文下方。点击摘要会打开右侧活动面板，按时间顺序展示思考、命令执行、文件处理等步骤和耗时。

模型边做边用一两句话说明正在做什么、发现了什么，这些过程说明以较淡的文字显示在状态行上方，不算正式回复；给出正式回复后，它们只留在活动面板里。如果任务没能给出正式回复就结束（例如用完了工具调用轮次），会保留最后一段过程说明，并提示结束原因。

- 运行中可以随时停止；同一会话运行中不能重复发送。
- 刷新页面、网络重连或暂时离开会话不会打断生成，返回后会从服务端恢复最新状态。

## 结果展示

最终内容回到对话主线：文本直接阅读，支持复制、追问和重新生成；图片以缩略图展示，点开进入查看器；视频就地播放；模型在沙箱里生成的文件会以文件卡片出现在回复中，可以预览和下载。模型挑出成果文件时，成果按它给的顺序（可附一句说明）排在回复末尾，处理过程中产生的脚本、中间数据等收进可展开的「过程文件」。

需要你做决定或补充信息时，模型会在回复末尾提问并给出选项：点一下选项就会作为你的下一条消息发出，也可以直接在输入框里用自己的话回答。

## 内容预览

HTML、Mermaid、Markmap 会在右侧内容预览面板渲染；Markdown、代码、JSON 和纯文本走同一个预览面板，支持源码切换。这些富媒体预览由富媒体扩展包提供，构建时关闭后消息按普通文本渲染，代码面板退化为只读高亮，文件卡片只保留下载。

## 来自其他渠道的会话

装了微信包的站点，用户可以在账号页绑定微信 Bot，通过微信直接对话。这些会话也会出现在侧边栏，网页端可以完整查看消息、文件和执行过程，但不能在网页端继续发送；底部会提示该会话来自哪个渠道。

## 设置

「设置」集中放置：通用（界面语言、界面主题：浅色 / 深色 / 跟随系统）、个人（自定义指令，AI 会按指令调整回答风格）、账号（登录方式绑定与密码）、数据（清空当前时间线的对话）、平台公告、用户协议。

装了商业包的站点还有「账户数据」页签：查看当前会员、到期时间、可用积分与账户明细，明细按页浏览；开启签到的站点也会显示每日签到入口。

点击「选购会员」「购买积分」或侧栏的「升级会员」，会打开独立全屏选购窗口，顶部可切换会员套餐和积分包。选择规格后再进入支付方式页，不会在选规格时自动下单。支付结果在原窗口内显示；返回套餐列表会保留所选规格。从账户数据进入时关闭窗口会回到原购买入口；从聊天进入时关闭回到聊天。积分不足提示直接打开积分包选购。

## 适合演示的任务

以下示例需要对应模型、沙箱软件或外部服务已经准备完成。

| 场景 | 用户可以这样说 | 结果重点 |
| --- | --- | --- |
| 文件分析 | 读取这个 Excel，找出异常数据 | 表格分析、结论和建议 |
| 文档生成 | 创建一份本周工作周报 | 可预览的文档结果 |
| 办公文件 | 生成一份带图表的 PDF 报告 | 文件卡和下载入口 |
| 数据处理 | 把这些 CSV 合并并去重，输出汇总表 | 沙箱命令执行和产物 |
| 图片理解 | 分析这张截图的 UI 问题 | 视觉分析和修改建议 |
| 翻译润色 | 把这段中文改成商务英文 | 翻译和润色版本 |
| 读书笔记 | 把这本书整理成分享稿 | 摘要、金句和行动清单 |

## 常用操作

回复完成后可以继续追问，也可以复制回复、重新生成或删除消息；点击回复下方的活动摘要可以回看这一轮的执行过程。
